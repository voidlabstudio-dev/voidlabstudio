# FORMA — Bespoke Furniture Studio

FORMA is a bilingual concept website created by VOIDLAB Studio for the bespoke furniture sector.

## Highlights

- Polish and English content
- URL-based language selection
- Responsive navigation and layouts
- Filterable project gallery
- Service and process sections
- Accessible enquiry form demo
- Optimized WebP imagery

## Stack

- React
- TypeScript
- Vite
- CSS

## Local development

```bash
npm install
npm run build
```
